# Версия проекта "Бюро находок"

**Название проекта:** Бюро находок  
**Версия:** 1.1.0  
**Дата релиза:** 20 апреля 2026 г.  
**Разработчик:** GitHub Copilot (автоматизированная разработка).  
**Технологии:** Django 6.0.1, Python 3.12.10, SQLite.  

## Описание проекта
Веб-приложение для публикации и просмотра объявлений о найденных или потерянных вещах. Включает систему управления клиентами с аутентификацией.

## Основные возможности (версия 1.1.0)
- **Объявления (Cards):**
  - Создание, просмотр, фильтрация по категориям и типам.
  - Загрузка изображений.
  - Генерация уникальных slug.

- **Клиенты (Clients):**
  - Регистрация клиентов с именем, email, телефоном и паролем.
  - Просмотр, редактирование, удаление клиентов.
  - Хэширование паролей для безопасности.
  - Уникальный email как логин.

- **Общие фичи:**
  - Главная рекламная страница с навигацией.
  - Простые HTML-шаблоны без стилей.
  - CSRF-защита форм.
  - Сообщения после операций (создание/обновление/удаление).

## Структура проекта
- **Приложение:** naxodki
- **Модели:** Card, Client
- **Формы:** CardForm, ClientForm
- **Представления:** Функциональные views для всех операций
- **URL:** Маршруты для всех страниц
- **Шаблоны:** HTML-шаблоны в templates/naxodki/
- **База данных:** SQLite (db.sqlite3)

## История версий
- **1.0.0 (начальная):** Базовое приложение для объявлений.
- **1.1.0 (текущая):** Добавлена система клиентов с паролями.

## Требования к запуску
- Python 3.12+
- Django 6.0+
- Установленные зависимости (pip install django slugify)

## Запуск
1. Активировать виртуальное окружение: `.venv\Scripts\activate`
2. Применить миграции: `python manage.py migrate`
3. Запустить сервер: `python manage.py runserver`
4. Открыть в браузере: http://127.0.0.1:8000/
