## Общее описание системы
Проект "Бюро находок" - это веб-приложение на базе Django, предназначенное для управления объявлениями о потерянных и найденных вещах. Пользователи могут создавать объявления (Card), просматривать их по категориям, искать. Добавлена система клиентов (Client) для управления пользователями с базовой аутентификацией (хэширование паролей).

### Основные компоненты:
- **Модель Card**: Объявления с полями title, slug, content, author, create_time, update_time, activity, location, category_id, item_type, image, city.
- **Модель Client**: Клиенты с полями name, email (уникальный), phone, password (хэшированный), created_at, updated_at.
- **Views**: Функционал для создания, просмотра, обновления и удаления объявлений и клиентов.
- **Templates**: HTML-шаблоны для отображения страниц, включая формы входа, регистрации, списка клиентов и т.д.
- **Static**: CSS и JS для стилизации и интерактивности.
- **Admin**: Админ-панель с Unfold для управления моделями.

## Что работает и что нет
### Работает:
- Создание, просмотр, обновление и удаление объявлений (Card).
- Система клиентов: CRUD операции.
- Аутентификация клиентов с хэшированием паролей.
- Админ-панель.
- Базовая навигация и формы.

### Возможные проблемы:
- Пароли клиентов хранятся в отдельной модели, но нет интеграции с Django auth (нет login/logout views для клиентов).
- В templates клиентов нет CSRF в формах удаления (только в detail.html).
- Нет валидации уникальности email при обновлении (только при создании).
- В ClientForm поле password не обязательн��, но в модели blank=False, что может вызвать ошибки.
- Нет обработки ошибок в views (например, если клиент не найден).
- В main.html ссылки добавлены, но не проверено, работают ли они корректно.
